# Android 1.0.3: Devi and messaging polish

Signed versionCode 4 published to GitHub Releases; Netlify download metadata updated after signature and bundle verification. Netlify deployment alone does not update installed APKs.

## Changes

- AI assistant display name, greeting and generation identity are Devi.
- Launcher is absent on chat routes and while Devi is open, keeping Send accessible. Elsewhere it levitates 7px over five seconds, respecting reduced motion, visibility and background pausing.
- Human chats use compact dark incoming/blue outgoing bubbles, embedded timestamps, less spacing and no repeated avatars/names. Header keeps the partner identity; no invented presence/read receipts.
- Login/create-account choices appear above fields with a short first-visit hint and inline authentication errors.
- Optional Remember my email stores only the email locally. Password inputs retain standard username/current-password/new-password autocomplete. Android enables WebView autofill and commits the selected password-manager session after successful authentication. Saving/autofill depends on the user's configured provider and WebView; there is no app-owned password vault or guarantee of an OS save prompt.
- JWT lifetimes remain one day for web and ten days for Android. Expired sessions still require authentication; saving credentials does not extend authentication.
- Authenticated, successfully persisted human messages enqueue sender names (80 characters maximum) and previews (240 maximum). Android notifications show these; locked-screen public notifications use generic text, subject to the user's Android settings. Existing account-binding, expiry, deduplication, active-conversation suppression and tap checks remain.
- Message previews pass through FCM and the temporary notification outbox; this is not end-to-end encrypted messaging. Outbox retention remains one day. Old APKs ignore the new fields and show generic notifications.

## Validation

- OTP updates also correct failed-delivery handling and align the five-minute code expiry/two-minute resend display. Frontend: 89 Node tests, focused ESLint and production web build passed.
- Backend: 38 Node tests passed, including preview persistence, authenticated sender identity and payload bounds.
- Spring: five isolated fast-chat/router tests passed.
- Android: debug assembly, JVM unit tests and lint passed. The owner subsequently built the signed release; its package, version, certificate and production bundle were verified.
- Mocked browser checks at 360/412/768/1440px passed for login mode switching, email-only storage, no password in localStorage, Devi naming, launcher removal during chats, levitation/reduced motion, compact timestamps and no horizontal overflow.
