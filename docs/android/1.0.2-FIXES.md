# Android 1.0.2 (version code 3)

The 1.0.2 APK is signed with the retained release identity, inspected and published. The website download metadata points to it; installed apps retain their previous UI until this APK is installed. The public artifact was downloaded anonymously and matched SHA-256 `502c362ea7b2025ebcb63fbaa885c007b621a06321e503386e144123e4c59f3c`.

Changes:
- Resume filenames truncate within the card; actions wrap onto their own row on small screens and have 44px targets. Upload/signature/save requests have bounded timeouts. Disabled-cloud failures explain the storage problem and preserve the old resume.
- MainActivity reserves status bars, cutouts, navigation bars and the keyboard outside the WebView. Capacitor's competing CSS inset handling is disabled, and CSS does not add the same insets again. This keeps sticky headers below the status bar while scrolling. Native PDF dialog inset handling remains independent.
- Profile screens hide developer search. The account menu closes on selection, route change, outside pointer events and Escape.
- New feed visitors see a short left/right swipe hint with a gentle finite animation. It respects reduced motion, can be dismissed, and stays dismissed for that local account after a successful card action or explicit dismissal. Existing swipe directions/buttons/API behavior are unchanged.

Validation: 89 frontend Node tests, web build and focused ESLint passed. Browser checks verified resume containment at 320/360/412/768/1440px and preservation on failed Cloudinary uploads; profile-menu dismissal and swipe-hint reduced-motion/success/reload behavior also passed. Android debug assembly, JVM tests and lint passed for the native inset change. An actual API 36 emulator instrumentation test measured branding clear of native status bars both before and after scrolling. No physical-phone confirmation is claimed for 1.0.2 yet.

Separate service fixes: Node now rejects missing Cloudinary upload settings early and has a read-only credential check. The owner corrected Render's Cloudinary configuration and confirmed an upload succeeds. Spring adds a bounded alternative model only after persistent primary Gemini HTTP 503 errors; its dedicated Java regression tests passed. These server changes do not require APK installation, but native layout/navigation/hint changes do.
